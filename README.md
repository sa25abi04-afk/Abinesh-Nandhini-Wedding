# Abinesh & Nandhini Wedding E-Invitation

Mobile-friendly Tamil + English traditional/cinematic wedding invitation.

## Files
- `index.html` — complete invitation website
- `assets/couple.jpg` — supplied couple photo

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open Settings → Pages.
4. Select the main branch and root folder.
5. Save; GitHub will provide the public invitation link.
